# Online Doctor Android App

Android Studio project for the Online Doctor app.

Backend is preconfigured to:
`https://online-doctor-m7hg.onrender.com`

Features:
- Pashto, Dari, English, Urdu UI
- AI health chat through the deployed Render backend
- Patient profile (age, weight, allergies, medicines, conditions)
- Voice input/output where Android WebView speech support is available
- Medicine label/photo upload and AI analysis
- Emergency/red-flag warning layer
- Local chat history

## Build APK
1. Open this folder in Android Studio.
2. Let Gradle sync finish.
3. Connect an Android phone or use an emulator for testing.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).

The OpenAI API key stays only on Render. Do not put it in this Android project.
